DEAD ZONE

2D 탑뷰 로그라이크 슈팅

몰려오는 적의 생성 위치와 공격 타이밍을 제어하고, 표시 방향과 실제 탄환 방향을 구분해 사격 흐름을 구현했습니다.

IMPLEMENTATION

구현과 문제 해결

01

스폰 후보 검사와 유한 재탐색

등록된 Transform 후보를 무작위로 선택하고, OverlapPoint와 LayerMask로 후보 위치 한 점을 검사합니다. Wall·Water에 해당하면 다시 선택하고 최대 10회 모두 실패하면 스폰을 취소합니다.

  • 검사를 통과한 후보가 있을 때만 풀에서 적을 획득
  • 스폰 탐색 횟수를 제한해 종료되는 경로 구성
  • 몬스터 크기와 이동 경로 검증은 별도 개선 범위
02

8방향 외형과 연속 조준의 구분

캐릭터 외형과 총구 위치는 8방향에 맞추되 탄환은 연속적인 마우스 조준 방향으로 발사합니다. 22.5도를 더해 가까운 45도 방향을 선택하고 % 8로 인덱스를 순환시킵니다.

  • Blend Tree에 MoveX·MoveY 전달
  • pelletCount만큼 탄환을 꺼내 각 방향을 무작위 회전
  • ±spreadAngle/2 범위로 산탄 각도 조정
03

접촉과 공격 활성 구간의 분리

일반 적의 몸 중심 물리 Collider와 공격 Trigger를 구분했습니다. 플레이어와 접촉하면 0.5초 대기 후 공격 Trigger를 켜고, 0.2초 뒤 끕니다.

  • 접촉 시 Static으로 전환해 이동 정지
  • 접촉 해제 시 Kinematic으로 전환해 추적 재개
  • 코루틴의 고정 시간으로 공격 판정 구간 제어

CORE LOGIC

가까운 8방향 총구 인덱스 선택

동작을 요약한 설명 코드입니다.
전체 구현은 연결된 GitHub에서 확인할 수 있습니다.

전체 소스 보기
if (angle < 0f) angle += 360f;
int directionIndex =
    Mathf.FloorToInt((angle + 22.5f) / 45f) % 8;

적용 범위

일반 적은 몸 중심의 물리 Collider와 공격 Trigger를 분리합니다. 공격 준비와 판정 활성 시간은 AttackProcess()의 코루틴으로 제어합니다.
