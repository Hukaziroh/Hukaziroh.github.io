NEOFORGE

모바일 공장 자동화 시뮬레이션

화면에 필요한 타일을 관리하고, 편집한 데이터가 생산 시뮬레이션으로 이어지도록 연결했습니다. 성능 개선은 에디터 Stats의 전후 캡처로 확인했습니다.

자원을 채굴하고 설비와 벨트를 배치해 생산 라인을 확장하는 3D 탑뷰 게임입니다. 고정 틱으로 생산을 진행하며, 메뉴에서 공장 배치와 전력 상태를 저장·복원합니다.

IMPLEMENTATION

구현과 문제 해결

01

화면 범위 기반 청크 컬링과 타일 재사용

기본 400×400 맵을 16×16 청크로 나누고, 0.05초마다 화면 모서리 광선과 바닥 평면의 교차점을 계산합니다. 여유 범위까지 포함해 필요한 청크를 선택하고, 타일을 풀에서 가져오거나 반환합니다.

  • FloorChunkManager의 코루틴으로 배치를 여러 프레임에 분산
  • 화면 범위를 벗어난 청크의 타일을 풀로 반환
  • 단일 전후 캡처에서 FPS 5.7→90.3, Batches 8,101→302 확인
02

SO 작성에서 JSON·ID 조회까지

DataExporter가 아이템·기계·레시피 SO를 AssetDatabase로 수집해 세 JSON 파일로 변환합니다. DataManager는 ID별 딕셔너리를 구성하고, GameDatabase는 데이터를 시뮬레이션 구조로 변환합니다.

  • Inspector에서 기존 아이템·기계·레시피 값 편집
  • 빌드에서는 persistentDataPath의 외부 JSON을 우선하고 Resources를 기본값으로 사용
  • 변경 적용에는 데이터·시뮬레이션 재초기화가 필요
03

광고 보상과 생산 배속의 분리

LevelPlay의 OnAdRewarded 콜백에서 SpeedBuffManager를 호출해 60초 동안 2배 생산 버프를 적용합니다. SimulationDriver는 deltaTime×배속 계수를 누적해 고정 틱 실행 횟수를 늘립니다.

  • Time.timeScale을 바꾸지 않고 생산 시뮬레이션만 가속
  • 버프 만료 시 배속을 1로 복구
  • 광고의 로드·표시와 보상의 수명을 별도 클래스에서 관리

CORE LOGIC

생산 시뮬레이션의 시간 누적

동작을 요약한 설명 코드입니다.
전체 구현은 연결된 GitHub에서 확인할 수 있습니다.

전체 소스 보기
// 전역 시간은 유지하고 생산 틱의 실행 횟수를 조절
accumulator += Time.deltaTime * speedMultiplier;
while (accumulator >= fixedDelta) {
    world.Tick(fixedDelta);
    accumulator -= fixedDelta;
}

적용 범위
