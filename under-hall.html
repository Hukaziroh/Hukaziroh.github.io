IMPLEMENTATION

구현과 문제 해결

01

기능별 컴포넌트와 공유 상태

PlayerMovement, PlayerAttack, PlayerDash를 분리하고 PlayerState로 입력과 동작을 조율했습니다. 대시로 전환할 때 공격을 취소하고, 사망·부활 상태에서는 입력을 제한합니다.

  • 기본·특수 공격 코루틴과 콤보·입력 버퍼를 CancelAttack()에서 정리
  • 반복 VFX·사운드와 Animator 플래그·재생 속도 복구
  • 공격 상태에서만 Idle로 복귀해 사망·부활 상태 보존
02

전투 씬 안에서 방 프리팹 교체

메인 메뉴와 전투 씬은 구분합니다. 전투 중 방 이동은 같은 씬에서 맵 프리팹만 교체해 Player·매니저·UI의 참조와 런 상태를 유지합니다.

  • isTransitioning으로 중복 전환 요청 제한
  • 공격 취소·페이드아웃·기존 맵 제거·새 맵 생성의 순서 제어
  • 카메라 경계와 플레이어 위치 갱신 후 StartRoom()으로 전투 재개
03

공격 판정과 경사면 이동 보정

공격 판정은 Collider[100] 버퍼를 재사용하고 OverlapSphereNonAlloc이 반환한 hitCount만 순회합니다. 이동은 Raycast로 지면 법선을 확인해 ProjectOnPlane으로 경사면에 투영합니다.

  • 물리 검색 결과 배열의 반복 할당 제거
  • 평지·내리막에서 하향 속도를 더해 지면 이탈 감소
  • 지면을 감지하지 못하면 기존 y 속도 유지

CORE LOGIC

재사용 버퍼를 사용하는 공격 판정

동작을 요약한 설명 코드입니다.
전체 구현은 연결된 GitHub에서 확인할 수 있습니다.

전체 소스 보기
private readonly Collider[] hitBuffer = new Collider[100];

int hitCount = Physics.OverlapSphereNonAlloc(
    attackPosition, attackRadius, hitBuffer, targetLayer);

for (int i = 0; i < hitCount; i++) {
    // 반환된 결과 범위만 처리
}

적용 범위

NonAlloc 적용은 검색 결과 배열의 반복 할당을 줄이는 범위입니다. 버퍼는 최대 100개의 Collider를 저장하며, 게임 전체의 메모리 할당이 없어지는 것은 아닙니다.
